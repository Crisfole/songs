# Songs

These are song sheets. Currently it's only chords and lyrics for Christmas songs.

Creating your version requires you to have the chordpro CLI installed.

Then you can execute christmas/config/build.sh to build the songbook in one go.

The font is Poppins (from Google) license in christmas/config/fonts.
